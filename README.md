# Smart Campus Information System 🎓

## 📌 Overview
This project is a Python-based Smart Campus Information System that integrates multiple modules for managing student data, course enrollment, file handling, and performance analytics.

## 🚀 Features
- Student Registration & Grade Evaluation
- Course Enrollment Management
- Student Record Management
- Sorting & Searching Algorithms
- Fee Calculation System
- File Handling Operations
- Directory Scanning with Exception Handling
- Performance Analytics using NumPy, Pandas & Matplotlib

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- File Handling
- OS Module

## 📂 Modules
- student_registration.py
- course_enrollment.py
- student_records.py
- search_sort_students.py
- fee_calculation.py
- file_manager.py
- directory_scanner.py
- performance_analytics.py
- main_application.py
